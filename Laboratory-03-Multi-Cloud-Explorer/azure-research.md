# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's public cloud computing platform. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, security, identity, and application development. Azure is particularly useful for organizations that already use Microsoft technologies and enterprise software.

## Global Infrastructure

Azure organizes its cloud infrastructure into geographic regions and data centers. Microsoft provides a large global footprint with many regions across the world, allowing organizations to choose deployment locations based on performance, availability, compliance, and data residency requirements.

## Cloud Management Console

The **Microsoft Azure portal** is the web-based management interface for Azure. It allows users to create, configure, monitor, and manage Azure resources. Administrators can manage virtual machines, storage, networking, databases, identity, security, and other cloud services from a centralized interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers for running Windows or Linux applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage is object storage for large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources. It supports subnets, routing, network security, and connectivity between cloud and on-premises resources.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service. It helps organizations manage users, applications, authentication, and access to resources.

## Three Advantages

1. **Strong Microsoft integration** – Azure works closely with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft technologies.
2. **Enterprise and hybrid capabilities** – Azure supports enterprise governance, security, identity, and hybrid cloud environments.
3. **Global infrastructure** – Azure provides many geographic regions for organizations that need globally distributed applications and data.

## Typical Enterprise Use Cases

- Windows Server workloads
- Microsoft 365 integration
- Enterprise application hosting
- Hybrid cloud environments
- Virtual desktop infrastructure
- Database applications
- Business intelligence and analytics
- Artificial intelligence and machine learning
- Enterprise identity and access management
