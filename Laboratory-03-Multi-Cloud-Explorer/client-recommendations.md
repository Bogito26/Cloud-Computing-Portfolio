# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

I recommend **AWS** for the startup because it provides a very broad selection of scalable services that can support a mobile application as the company grows. The startup can begin with relatively small resources and expand them as user demand increases. AWS also provides managed services that can reduce the amount of infrastructure the startup needs to operate itself. This combination of scalability and service variety makes AWS a strong choice for a growing application company.

### Recommended Services

- **Amazon EC2** – scalable compute capacity for application workloads.
- **Amazon S3** – storage for images, files, backups, and application assets.
- **Amazon RDS** – managed relational database service for application data.

## Client B – University

### Recommended Platform: Microsoft Azure

I recommend **Microsoft Azure** because the university already uses Windows Server and Microsoft 365. Azure provides strong integration with Microsoft's identity, server, productivity, and hybrid-cloud technologies, which can simplify administration and user access. The university can extend existing Microsoft skills and infrastructure into the cloud rather than adopting an unrelated ecosystem. Azure is therefore a natural choice for modernizing the university's existing Microsoft-based environment.

### Recommended Services

- **Azure Virtual Machines** – run Windows Server workloads in Azure.
- **Microsoft Entra ID** – manage identities, authentication, and access.
- **Azure Virtual Network** – connect and secure cloud resources and hybrid environments.

## Client C – Data Analytics Company

### Recommended Platform: Google Cloud Platform

I recommend **Google Cloud Platform (GCP)** for a data analytics company because Google has strong capabilities in data processing, analytics, and artificial intelligence. Google Cloud provides managed services that can help organizations collect, process, analyze, and visualize large datasets without maintaining all of the underlying infrastructure. Its data platform is also well suited to organizations that expect to add machine learning to their analytics workflows. GCP would therefore provide a strong foundation for a data-driven company.

### Recommended Services

- **BigQuery** – serverless data warehouse and analytics platform.
- **Cloud Storage** – scalable object storage for datasets and files.
- **Vertex AI** – platform for building and deploying machine learning and AI solutions.

## Client D – Global Enterprise

### Recommended Platform: AWS

I recommend **AWS** for a global enterprise that requires broad cloud capabilities and worldwide deployment. AWS provides a large portfolio of infrastructure, security, database, networking, and application services that can support complex enterprise environments. Its global Regions and Availability Zones allow organizations to design applications for geographic distribution and resilience. AWS also gives a large enterprise flexibility to support many different workloads on one cloud platform.

### Recommended Services

- **Amazon EC2** – scalable compute for enterprise applications.
- **Amazon S3** – durable object storage for enterprise data and backups.
- **Amazon VPC** – private networking and network security for cloud workloads.

## Recommendation Summary

| Client | Recommended Platform | Main Reason |
|---|---|---|
| Client A – Startup | AWS | Scalable services and broad ecosystem |
| Client B – University | Microsoft Azure | Strong Microsoft and hybrid integration |
| Client C – Data Analytics Company | Google Cloud | Strong analytics, data, and AI capabilities |
| Client D – Global Enterprise | AWS | Broad enterprise services and global infrastructure |
