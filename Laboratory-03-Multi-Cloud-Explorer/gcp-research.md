# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's public cloud computing platform. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, machine learning, and application development. Google Cloud is especially well known for data analytics, AI, and Kubernetes-based cloud-native workloads.

## Global Infrastructure

Google Cloud organizes its infrastructure into **regions** and **zones**. A region is a geographic location containing multiple zones. Zones are isolated locations within a region and can be used to distribute workloads for higher availability and resilience. Google Cloud operates a large global infrastructure and network across multiple continents.

## Cloud Management Console

The **Google Cloud Console** is the web-based management interface for Google Cloud. Users can create and manage resources, configure services, monitor workloads, manage projects, and control access permissions from a centralized interface.

## Four Core Services

### 1. Compute Engine

Google Compute Engine provides scalable virtual machines for running applications and other workloads.

### 2. Cloud Storage

Google Cloud Storage provides object storage for files, application data, backups, media, archives, and other information.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking for cloud resources. It supports networks, subnets, firewall rules, routes, and connectivity between resources.

### 4. Cloud IAM

Google Cloud Identity and Access Management (IAM) controls who can access resources and what actions they are allowed to perform through roles and permissions.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides extensive infrastructure and managed services for AI and ML workloads.
2. **Kubernetes expertise** – Google Kubernetes Engine (GKE) provides managed Kubernetes for containerized applications.
3. **Powerful global network** – Google Cloud's global infrastructure and network support high-performance applications across geographic locations.

## Typical Enterprise Use Cases

- Artificial intelligence and machine learning
- Big data and analytics
- Kubernetes and containerized applications
- Web application hosting
- Data warehousing
- Application modernization
- Global applications
- Research and scientific computing
- Real-time data processing
