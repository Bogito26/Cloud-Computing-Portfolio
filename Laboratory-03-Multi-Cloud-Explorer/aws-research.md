# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform. It provides on-demand services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development. AWS launched its first services in 2006 and has grown into one of the world's largest public cloud platforms.

## Global Infrastructure

AWS organizes its infrastructure into geographic **Regions** and **Availability Zones (AZs)**. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This design allows organizations to distribute workloads for higher availability and resilience. AWS provides a large global infrastructure with Regions, Availability Zones, and additional edge locations around the world.

## Cloud Management Console

The **AWS Management Console** is a web-based interface for accessing and managing AWS services. Users can create resources, configure networking, manage identities and permissions, monitor workloads, and control cloud infrastructure through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable virtual servers for running applications and workloads in the AWS cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used for application data, files, backups, media, archives, and other data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides logically isolated networking for AWS resources. It supports subnets, routing, security groups, and other network controls.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources. Administrators can manage users, groups, roles, policies, and permissions.

## Three Advantages

1. **Broad service portfolio** – AWS provides services across computing, storage, databases, networking, security, analytics, AI, and many specialized workloads.
2. **Global infrastructure** – Its worldwide Regions and Availability Zones support applications that need geographic reach and high availability.
3. **Scalability** – AWS resources can be increased or decreased as application demand changes, helping organizations adapt to growth.

## Typical Enterprise Use Cases

- Web and mobile application hosting
- Enterprise application modernization
- Backup and disaster recovery
- Data analytics
- Artificial intelligence and machine learning
- E-commerce platforms
- Database hosting
- Global application deployment
