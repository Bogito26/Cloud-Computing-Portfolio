# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the basic responsibilities of a cloud infrastructure engineer. The activities focus on accessing a cloud-based Linux environment through KillerCoda, exploring Linux, gathering system information, organizing files, and documenting technical work in a GitHub portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Maintain a professional GitHub portfolio.
- Document technical work using Markdown.

## Activities Performed

1. Launched an Ubuntu Linux Playground using KillerCoda.
2. Created and logged in to a new Linux user account with sudo access.
3. Recorded the username, working directory, and hostname.
4. Investigated the Linux distribution, kernel, CPU, memory, and disk space.
5. Created the required workspace directory structure.
6. Created and viewed the `about-me.md` file.
7. Organized the laboratory documentation and evidence screenshots in GitHub.

## Linux Commands Used

```bash
whoami
pwd
hostname
sudo adduser <username>
sudo usermod -aG sudo <username>
su - <username>
cat /etc/os-release
uname -r
lscpu
free -h
df -h
mkdir -p
ls -la
cat
```

## Skills Learned

- Basic Linux navigation and administration
- User and permission management
- System information gathering
- Linux file and directory organization
- Markdown documentation
- GitHub repository organization
- Technical evidence collection
