# Reflection

This laboratory introduced me to the Linux environment used by cloud infrastructure engineers. I learned how to access a cloud-based Linux playground, create and manage a user account, navigate directories, and collect basic system information.

I also learned the importance of organizing technical work and documenting activities using Markdown and GitHub. The activity showed me that cloud engineering is not only about operating infrastructure but also about maintaining clear documentation and evidence of completed work.

Overall, this mission gave me a foundation for future laboratory activities involving cloud infrastructure, Linux administration, containers, Kubernetes, monitoring, and enterprise systems.
